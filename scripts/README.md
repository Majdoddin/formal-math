# Scripts of "Thin matrix products and lossless reductions from 3SUM, Exact Triangle and APSP, with a dichotomy for coordinatewise problems"

This folder holds the computer checks of this paper by Ruhollah Majdoddin, version 2 of November 2026
([PDF](../papers/thin-matrix-products-v2/main.pdf)). They are the ancillary files of its arXiv submission: the files
of version 1 (arXiv:2610.17420, 12 October 2026), unchanged except for one sentence in the docstring of
`exact_ceiling.py`, and the files added in version 2, whose names (r and a number) are those of the author's research
record. Section 30.1 and Table 16 of version 2 list them.

[`README.txt`](README.txt) is the ancillary files' own README. It lists every file with its kind (P re-checks a
proved statement, C is part of a computer-assisted proof, N computes a numerical value that is not proved), what it
needs, how long it runs and which statements of version 2 it supports, and it gives the command for each.

Each script added in version 2 has its recorded output beside it, `NAME_out.txt`. The scripts of version 1 have the
outputs recorded for version 1, `NAME.out`, or `NAME.MODE.out` for a script with several modes. This folder as
published with version 1, with that version's README and item numbers, is at commit
[`63e9490`](https://github.com/Majdoddin/formal-math/tree/63e9490d3b5d62bf8b9f7f0a8103b0e409564a9d/scripts).
